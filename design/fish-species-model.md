# 鱼种建模优化方案

## 目标

当前 `game/src/fish.ts` 有 17 个鱼种名称，但实际只共享 5 个通用外形。鱼种差异主要来自颜色和稀有度，玩家很难一眼辨认不同物种。

本次优化把鱼种定义成可复现的 `SpeciesProfile`，让每个鱼种拥有独立的：

- 体型比例：尾部收窄、头部体积、身体宽度；
- 鳍形比例：背鳍、胸鳍、尾鳍展开度；
- 花纹类型：纯色、条纹、斑点、面罩、发光；
- 行为参数：巡游速度、转向速度和逃逸半径。

## 实现方式

- `rollFish(seed, zone, depth)` 仍使用原来的 seed 和随机顺序，保证同一个 seed 继续生成同一稀有度、鱼种和 NFT 属性。
- `FishSpec` 不增加必填字段，已有 `localStorage` 存档和已铸造 NFT 可以继续读取。
- `speciesProfile()` 为旧存档提供按鱼种名的兼容解析；遇到未知鱼种时使用安全的通用 profile。
- `buildFishMesh()` 使用 profile 生成身体环、鳍和花纹；不引入外部模型文件，仍保持低多边形风格。
- `Fish.update()` 复用临时向量，减少每条鱼每帧的对象分配；行为参数由鱼种 profile 驱动。

## 评审重点

1. 17 个鱼种的体型、花纹和行为参数是否符合游戏美术方向。
2. 颜色仍由稀有度和 seed 决定，是否需要改成更明确的物种配色。
3. 鱼种差异是否足够明显；如果需要，可继续细化嘴型、背鳍数量或群游行为。

这项改动是程序化建模优化，不是鱼类图片分类模型。现有海鸥图片数据与鱼种模型没有标签关系，因此没有用于训练鱼种分类器。
