# 《屏息》水下装备与配件 3D 建模设计规范

> HackRU Fall 2026 · Breathless
> 对应模块：`game/src/accessories.ts`、`game/accessory-preview.html`、`game/src/accessory-preview.ts`

本文档记录《屏息》（Breathless）水下装备与配件的程序化低多边形（Low-Poly Faceted）3D 建模设计、材质规范与槽位体系。所有模型均采用原生 Three.js 分面几何体程序化生成，支持 3 级升级外观与实时交互检查。

## 2. 建模风格与材质系统

游戏整体继承统一的低多边形折纸雕塑风格（Polyhedral PBR），所有配件遵循以下设计铁律：

1. **分面法线**：统一开启 `flatShading: true`，利用几何体切面折射光线，摒弃平滑着色与笨重外部贴图。
2. **调色板体系**：
   - **湿衣 / 硫化橡胶**：`#16222b`、`#1d2b3a`、`#202d38`（roughness 0.85–0.95）；
   - **高能警示橙**：`#ff7a3d`、`#e27a35`（roughness 0.45）；
   - **深海青 / 荧光绿**：`#27c4b8`、`#195663`、`#40ffcc`；
   - **精密金属与钛合金**：`#9aaeb5`、`#344956`、`#1c2830`（metalness 0.75–0.90）；
   - **深海红光滤光片**：`#c91c28`（Physical 材质，透光度 0.78，微弱自发光）；
   - **高光镀铬与深渊金**：`#dce8ec`（镜面反射）、`#e5b642`（Lv3 专属黄金勋章）。
3. **分级视觉进化**：每个配件均支持 Lv1（基础工程原色）、Lv2（强化合金结构与副色导轨）、Lv3（深渊钛金勋章与高阶流体力学组件）。

## 3. 13 款配件建模细节规范

### 3.1 脚蹼：流线脚蹼 / 竞速脚蹼 (`streamlined-fins`)
- **几何结构**：双侧脚蹼组，长刀锋多边形折面碳纤翼板（向下倾斜 7° 贴合人体工学打腿姿态）；双侧高立面减阻导轨（`#ff7a3d`）；中央深色分流泄水脊槽；外侧减阻立式小翼（Winglets）；后跟不锈钢弹簧足带扣。
- **升级演进**：Lv1 聚合物韧性刀锋；Lv2 碳纤强化横梁与钛合金张力片；Lv3 顶端导流喷口、双翼梢小翼与黄金加固徽记。

### 3.2 脚蹼插件：分叉导流片 (`split-flow-vanes`)
- **几何结构**：双分叉水翼片组（夹角 14°，形成流体力学 V 型扩张槽）；重型八边形快拆锁紧夹箍，配备双六角钛合金锁紧螺栓；内外双导流鳍片与喷流喷嘴。

### 3.3 脚蹼插件：静音鳍片 (`silent-fins`)
- **几何结构**：仿生锯齿消音边缘（基于鲸鳍结节与猫头鹰羽缘原理打破湍流涡旋）；消音复合硅胶减振衬垫（哑光深灰色）；外缘压力平衡微槽；中心防颤减振软胶脊。

### 3.4 头灯核心：高亮探照灯 (`searchlight-core`)
- **几何结构**：八边形数控航天铝外筒；深凹多边形反光杯与自发光光学晶体（`#e9fbff`，emissive `#67d8e4`）；后筒四联/六联径向散热鳍片；弧形前额贴合底板与尼龙防滑头带；防水电池仓连结螺旋抗拉线缆。
- **升级演进**：Lv1 单光斑深筒；Lv2 双联并列矩阵透镜；Lv3 三联聚光晶体与黄金压环。

### 3.5 灯光配件：长焦反射杯 (`telephoto-reflector`)
- **几何结构**：加长型多边形阶梯锥筒准直罩；内壁高反射镜面镀铬抛物层（metalness 0.98）；前置三道同心消光防眩环；前端聚光凸透镜面环与双侧快拆卡销。

### 3.6 灯光配件：广角扩散罩 (`wide-angle-diffuser`)
- **几何结构**：半球形低多边形磨砂扩散球冠（半透明 Physical 材质）；喇叭口外扩柔光导流环（警示橙）；前置六边形蜂窝分光切面矩阵；快拆防脱硅胶拉环。

### 3.7 灯光配件：红光滤镜 (`red-light-filter`)
- **几何结构**：深红高饱和单色滤光玻璃片；顶置多边形翻折机械铰链（可一指上下翻起）；侧面大尺寸手套防滑操作拨片；底座磁吸定位闭锁块。

### 3.8 应急装备：应急气瓶 (`emergency-tank`)
- **几何结构**：0.4L 微型便携无缝高压储气铝瓶；瓶体保护橡胶托底；集成式一二级一体化呼吸咬嘴（肉色硅胶咬胶）；亮黄高反差一键强排水应急顶阀；发光微型高压压力表；双道抗拉胸带挂载锁具。

### 3.9 身体：流线潜水服 (`streamlined-wetsuit`)
- **几何结构**：解剖学贴合背负躯干套件；胸侧与脊柱流体力学导水脊槽（青绿/警示橙嵌色）；胸前菱形加强防滑上膛装甲块；护肩多边形分节减水阻板；下摆鱼尾快扣闭锁螺栓。

### 3.10 身体：配重平衡带 (`weight-balance-belt`)
- **几何结构**：高弹性深灰抗海水老化橡胶腰带；马赛式快速脱卸不锈钢滚轴插扣（带红/橙快速拉开舌片）；4 块对称流线切角铅合金配重块（带穿带槽与限位卡扣）；侧置潜水装备挂载 D 型环。

### 3.11 手部：防滑捕捞手套 (`anti-slip-gloves`)
- **几何结构**：成对低多边形潜水手套（自然微屈抓握待机手型）；手心掌面与指腹凯夫拉多面体摩擦防滑铠甲块；指关节橙色冲击吸收护块；加长腕部弹性袖口与魔术贴拉紧带。

### 3.12 面镜：防雾偏光面镜 (`polarized-mask`)
- **几何结构**：双泪滴型大视野低容积潜水面镜；双层偏光镀膜水滴镜片（祖母绿/青金偏光色泽，反射水面多余杂光）；易捏鼻囊防压耳槽；钛金加固镜桥；微调齿扣分叉防滑硅胶带。

### 3.13 胸口插件：回声声呐 (`echo-sonar`)
- **几何结构**：八边形钛合金防水抗压舱体（额定耐压 500 米）；前置同心环相控阵换能器探头；环形发光脉冲状态指示圈（`#40ffcc`，自发光）；顶部大手套按压触发键；后背 4 点式快拆胸挂吊架与泄压阀。

## 4. 交互式 3D 检查与素材导出

运行开发服务器：
```bash
npm --prefix game run dev
```

在浏览器中打开：
**`http://localhost:5173/accessory-preview.html`**

**功能亮点**：
- **实时切换**：可在全部 13 款配件中一键切换，包含槽位与阶段过滤；
- **三档外观**：自由切换 Lv1 基础、Lv2 强化、Lv3 深渊外观；
- **全方位检查**：支持 OrbitControls 360° 旋转缩放、`W` 键切换线框模式、`R` 键切换自动旋转；
- **素材导出**：
  - **📷 导出透明 PNG**：截取当前视角的纯净半透明透明背景产品图；
  - **📦 导出 GLB 模型**：一键导出包含标准材质与网格分面的标准二进制 GLB 文件，可直接导入 Blender 或用于 Web3 资产展示。
